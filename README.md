---

## 🚀 Features

- **UNDERSTAND • PREDICT • DEFEND**: Hero showcase with official metallic eagle shield emblem and animated cyber radar scans.
- **Interactive Continuous Defense Loop**: 8-stage interactive stepper explaining Digital Twin, Graph Traversal, Telemetry, Correlation, AI Analysis, and Closed-Loop Containment.
- **Interactive Threat Simulator Terminal**: Browser-side live kill-chain simulator with real-time risk score drops and containment feedback.
- **Performance & Benchmark Stats**: 71/71 tests passing, <100ms path discovery, 100% citation grounding.
- **Vercel Zero-Config Ready**: Deploys instantly to Vercel with zero required environment variables.

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production (Vercel)
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
